# SideNote
an extention for Edge

## 整体定位
一个让网页摘录真正产生意义的浮动侧边栏笔记本。

Edge/Chrome 浮动侧边栏，让您在浏览网页时，选中文字即可摘录保存，并把摘录和自己的笔记放进同一本笔记本里，形成有上下文的完整记录。让你在不离开当前网页的情况下，摘录文字、写笔记、分笔记本管理。所有数据本地保存，不用装额外的app。

## 为什么会有 SideNote？

我一直在寻找一种极简的网页摘录方式：选中 → 点击 → 存下，不用复制、不用切换 App。看到什么值得留下的句子，随手一点就存下来了。通过搜索发现，Quick Notes Sidebar 做到了这一点，我很喜欢。

但用久了发现一个问题：每条摘录都是孤立的，一条条散落在列表里，无法把相关内容统一保存。一句摘录本身没有上下文，很快就忘了当时为什么存它。我真正需要的是——把相关的摘录和我的思考放在一起，让摘录产生意义。

于是有了  **SideNote**。

它保留了「选中即存」的便捷，同时引入完整的笔记本概念：你可以在一个笔记本里自由书写，也可以随时插入网页摘录。你可以把相关的摘录、自己的分析、零散的想法都放在一起。摘录不再是一条条孤立的句子，而是你思考的一部分。笔记与摘录混合编辑，按主题或项目聚合，不再碎片化。


## 核心概念
笔记本（Notebook）：一个独立的文档容器，按主题或项目分类（如“读书笔记”“项目需求”）。

摘录（Highlight）：从网页选中的文字片段。

个人笔记（My Note）：您自己键盘输入的文字，可放在任何笔记本中。

## 功能模块
1. 摘录捕获（继承原功能并增强）
在侧边栏选择一个笔记本打开，并光标定位到想插入文字的位置。
选中任意网页文字，自动在选区旁出现 “save notes” 按钮。
文字将存入打开的笔记本。（没有选笔记本就将新建笔记本，没有定挂光标位置将自动插入到笔记本最后）
可选是否添加标签。

2. 混合编辑
每个笔记本是一个富文本编辑区域，您可以：
自由键入文字（支持粗体、斜体、下划线、有序/无序列表）。
随时插入摘录，摘录内容自动套用浅灰色背景块。个人笔记文字保持默认白色背景。
每条摘录保留网页URL和时间戳（可折叠/显示，默认折叠）。

3. 笔记本管理（全新）
左侧或顶部有笔记本列表：
创建新笔记本（命名）。
重命名、删除（删除笔记本时，内部内容先移入回收站）。

4. 全局搜索（继承）
在侧边栏顶部提供搜索框，实时过滤当前笔记本内容（或跨所有笔记本搜索），按关键词匹配。

5. 回收站与恢复（继承）
删除的摘录或笔记本整体内容，进入回收站。
可从回收站还原到原笔记本，或永久删除。

6. 数据导出（继承）
每个笔记本可单独导出为 .txt 文件，或一键导出所有笔记本。

7. 界面设计
浮动侧边栏，固定在右侧，随时收起/展开。
白蓝主题，简约不干扰浏览。

## 典型使用流程（示例）
浏览文章 → 发现想保存的字句→ 打开“项目A”笔记本定位想插入字句的位置 → 选中一段关键句 → 点击“保存到笔记” → 存好。

打开侧边栏 → 进入“项目A”笔记本 → 在摘录下方自己写一段分析（加粗关键点）。

再选中另一段文字 → 直接存入同一个“项目A”笔记本 → 新摘录自动追加到末尾，以灰色块区分。

后期搜索关键词，快速定位所有相关摘录和评论。

完成后，可将单个笔记本导出为 `.txt`，或一键导出全部。

##
SideNote 的灵感来自 Quick Notes Sidebar 的极简摘录体验，但重新设计了笔记的组织方式：

| 功能维度 | Quick Notes Sidebar（原版） | SideNote（改进版） |
|------|---------------------|----------|
| 笔记组织 | 扁平列表，摘录与笔记分离 | 多笔记本，摘录与笔记混合编辑 |
| 摘录插入位置 | 固定追加到末尾 | 可光标定位插入，也可自动追加 |
| 摘录视觉区分 | 无 | 浅灰色背景块，与个人笔记区分 |
| 来源追溯 | 无 | 保留网页 URL 和时间戳 |
| 笔记本管理 | 无 | 创建、重命名、删除、回收站 |
| 导出 | 单条笔记导出 | 单笔记本导出 + 一键全部导出 |
| 搜索范围 | 当前笔记 | 当前笔记本 + 跨笔记本搜索 |

## 技术栈（开发中）

- 浏览器扩展 Manifest V3
- 原生 JavaScript + IndexedDB（本地数据存储）
- 富文本编辑器（ContentEditable / Quill）
- 白蓝主题 CSS

## 总结

SideNote 在原版 **Quick Notes Sidebar** 的基础上，核心改进在于引入了 **“笔记本”** 这一组织维度——原版将所有笔记扁平存放，摘录内容碎片化；而 SideNote 鼓励用户通过笔记本的归纳方式，可在笔记本内自由定位插入摘录，便于用户自由书写想法、打造真正的知识库而非刻板碎片化的摘录。此外，SideNote 增强了摘录的视觉区分（灰色背景）、来源追溯（URL+时间戳）、导出能力（一键全部导出）以及标签功能，使笔记管理从“随手记”升级为“体系化管理”。
