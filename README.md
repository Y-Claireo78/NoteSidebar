# SideNote
an extention for Edge

## 整体定位
一个 Edge/Chrome 浮动侧边栏，让您在不离开当前网页的情况下，摘录文字、写笔记、分笔记本管理，所有数据本地保存，不用装额外的app。

## 核心概念
笔记本（Notebook）：一个独立的文档容器，按主题或项目分类（如“读书笔记”“项目需求”）。

摘录（Highlight）：从网页选中的文字片段。

个人笔记（My Note）：您自己键盘输入的文字，可放在任何笔记本中。

## 功能模块
1. 摘录捕获（继承原功能并增强）
在侧边栏选择一个笔记本打开，并光标定位到想插入文字的位置。
选中任意网页文字，自动在选区旁出现 “save notes” 按钮。
文字将存入打开的笔记本。（没有选笔记本就将新建笔记本，没有定挂光标位置将自动插入到笔记本最后）
可选是否添加标签。

2. 混合编辑
每个笔记本是一个富文本编辑区域，您可以：
自由键入文字（支持粗体、斜体、下划线、有序/无序列表）。
随时插入摘录，摘录内容自动套用浅灰色背景块。个人笔记文字保持默认白色背景。
每条摘录保留网页URL和时间戳（可折叠/显示，默认折叠）。

3. 笔记本管理（全新）
左侧或顶部有笔记本列表：
创建新笔记本（命名）。
重命名、删除（删除笔记本时，内部内容先移入回收站）。

4. 全局搜索（继承）
在侧边栏顶部提供搜索框，实时过滤当前笔记本内容（或跨所有笔记本搜索），按关键词匹配。

5. 回收站与恢复（继承）
删除的摘录或笔记本整体内容，进入回收站。
可从回收站还原到原笔记本，或永久删除。

6. 数据导出（继承）
每个笔记本可单独导出为 .txt 文件，或一键导出所有笔记本。

7. 界面设计
浮动侧边栏，固定在右侧，随时收起/展开。
白蓝主题，简约不干扰浏览。

## 典型使用流程（示例）
浏览文章 → 发现想保存的字句→ 打开“项目A”笔记本定位想插入字句的位置 → 选中一段关键句 → 点击“保存到笔记” → 存好。
打开侧边栏 → 进入“项目A”笔记本 → 在摘录下方自己写一段分析（加粗关键点）。
再选中另一段文字 → 直接存入同一个“项目A”笔记本 → 新摘录自动追加到末尾，以灰色块区分。
后期搜索关键词，快速定位所有相关摘录和评论。

## 本插件基于已有的 Quick Notes Sidebar 插件为基础做出改进：

| 功能维度 | Quick Notes Sidebar（原版） | SideNote（改进版） | 改进说明 |
|---|---|---|---|
| **笔记本体系** | ❌ 无（扁平笔记，无分类容器） | ✅ 多笔记本管理 | 新增“笔记本”作为一级容器，支持按主题/项目分类管理 |
| **摘录用灰色背景区分** | ❌ 无 | ✅ 摘录自动套灰背景 | 摘录与手写笔记视觉区分更清晰 |
| **摘录插入位置控制** | ❌ 固定追加到末尾 | ✅ 光标定位插入 | 可在笔记本任意位置插入摘录，而非仅末尾 |
| **URL+时间戳** | ❌ 无 | ✅ 每条摘录自带来源 | 保留网页 URL 和时间戳，默认折叠 |
| **笔记本列表** | ❌ 无 | ✅ 左侧/顶部笔记本列表 | 快速切换、管理多个笔记本 |
| **新建笔记本** | ❌ 无 | ✅ 创建/重命名/删除 | 完整笔记本生命周期管理 |
| **删除保护** | ✅ 回收站可恢复 | ✅ 回收站 + 还原 | 功能一致 |
| **导出** | ✅ 单笔记导出 .txt | ✅ 单笔记导出 + 一键全部导出 | 导出能力增强 |
| **富文本编辑** | ✅ 粗体/斜体/下划线/列表 | ✅ 同上 | 功能一致 |
| **全局搜索** | ✅ 实时搜索 | ✅ 实时搜索 + 跨笔记本搜索 | 搜索范围扩展 |
| **摘录捕获** | ✅ 选区旁出现保存按钮 | ✅ 同上 + 标签功能 | 新增标签能力 |
| **设计主题** | 白绿主题 | 白蓝主题 | 配色调整 |

## 总结

SideNote 在原版 **Quick Notes Sidebar** 的基础上，核心改进在于引入了 **“笔记本”** 这一组织维度——原版将所有笔记扁平存放，摘录内容碎片化；而 SideNote 鼓励用户通过笔记本的归纳方式，可在笔记本内自由定位插入摘录，便于用户自由书写想法、打造真正的知识库而非刻板碎片化的摘录。此外，SideNote 增强了摘录的视觉区分（灰色背景）、来源追溯（URL+时间戳）、导出能力（一键全部导出）以及标签功能，使笔记管理从“随手记”升级为“体系化管理”。
